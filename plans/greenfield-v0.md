# Ablagent greenfield v0

## Completion boundary

Deliver a private, independently runnable Python repository implementing the DWM/DWMIP protocol and a synthetic reference engine. Do not copy model weights, directions, prompts, results, run history, operational endpoints, credentials, partner material, model-specific parameters, or previous implementation history.

## Architecture

- Typed, versioned graph/site/space/writer/tensor identities; descriptive complex-graph IR, not a general graph executor.
- Exactly one v0 intervention: single-coordinate, unit-direction rank-one output update on a declared dense `out x in` matrix.
- Exact baseline, writer, tensor, bank, direction, algorithm, and codec bindings. Same shape never implies compatibility.
- NumPy CPU reference math, Pydantic boundary validation, safe `safetensors` payloads, canonical JSON manifests, independently verifiable JSON evidence. No SQLite requirement.
- Bounded, deterministic proposal-only planner; separate validation and explicit compile invocation. No agent execution or approval privilege.
- Licensed project-authored synthetic banks, role separation, private-holdout eligibility restrictions, and fail-closed required gates.
- Original architecture-navigation and DWMIP method documentation with explicitly limited support claims.

Real-model support, arbitrary checkpoint code execution, universal architecture discovery, automatic cross-writer/model transfer, multi-direction composition, general quantized editing, production serving, public publishing, self-approval, or any real-world efficacy/safety certification.
